## 📱 About

**LifePilot** is a full-featured mobile app built with React Native and Expo that helps users take control of their daily habits and nutrition. It combines gamification with AI-powered features to make healthy living engaging and sustainable.

---

## ✨ Features

### 🎯 Habit Tracking
- Create, edit and delete habits with custom icons, colors and categories
- Set daily goals with custom units (km, ml, pages, minutes, etc.)
- Partial progress tracking — log progress towards your goal throughout the day
- Mark habits as complete with a single tap
- Long press to view habit details, streak and photo history

### 🔥 Gamification
- XP system — earn XP every time you complete a habit
- Level up as you accumulate XP
- Streak tracking — consecutive days of habit completion
- Achievement badges (First Step 🌟, On Fire 🔥, Dedicated 💎)

### 📸 Habit Photos
- Add photo proof of completed habits via camera or gallery
- Photos uploaded securely to Supabase Storage
- View full photo history per habit

### 🔔 Smart Reminders
- Schedule daily reminders at a specific time
- Multiple frequency options: once, every 30 min, every hour, every 2 hours
- Set custom start and end time for repeated reminders

### 📊 Statistics
- Weekly bar chart of habit completions
- 30-day activity heatmap (GitHub-style)
- Total completions, habit count and best streak overview

### 🥗 Diet & Nutrition
- Log daily meals with full calorie and macro tracking (protein, carbs, fat)
- **AI meal analysis** — take a photo of your food and Gemini AI estimates the nutritional values
- Track consumed vs goal calories with visual progress bar
- Weekly diet plan generated by AI based on your personal goals
- Support for dietary restrictions (gluten-free, vegetarian, etc.)
- Manually add, edit or delete individual meals from your diet plan

### 👤 Profile & Preferences
- Level and XP progress bar
- Achievement badges showcase
- Dark / Light mode toggle
- Language selector — Portuguese 🇵🇹 / English 🇬🇧

## 🗄️ Database Schema

```sql
-- User profiles (extends Supabase auth)
profiles (id, username, avatar_url, xp_total, level, created_at)

-- Habits
habits (id, user_id, name, icon, color, category, frequency,
        goal_value, goal_unit, reminder_time, reminder_frequency,
        reminder_end_hour, archived, created_at)

-- Daily habit completion logs
habit_logs (id, habit_id, completed_at, photo_url, note, value)

-- Daily meal entries
meals (id, user_id, name, photo_url, calories, protein,
       carbs, fat, meal_type, eaten_at)

-- User daily nutrition goals
diet_goals (id, user_id, daily_calories, daily_protein,
            daily_carbs, daily_fat)

-- Weekly AI-generated or manual meal plan
diet_plan (id, user_id, day_of_week, meal_type, meal_name,
           calories, protein, carbs, fat, notes)
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Expo CLI
- Supabase account
- Google Gemini API key

### Installation

```bash
# Clone the repository
git clone https://github.com/FontouraC18H22O2/-lifepilot.git
cd -lifepilot

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your credentials
```

### Environment Variables

```env
EXPO_PUBLIC_SUPABASE_URL=your_supabase_project_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
EXPO_PUBLIC_GEMINI_API_KEY=your_gemini_api_key
```

### Start the development server

```bash
npx expo start
```

---

## 🔒 Security

- All credentials are stored in environment variables and never committed to the repository
- Row Level Security (RLS) enabled on all Supabase tables
- Users can only access their own data
- Sensitive tokens stored using Expo Secure Store
